MIDI connection

The browser talks to the MIDI interface directly (Web MIDI) - allow MIDI / SysEx access when it asks. Auto-detect sends an identity request on every port and MIDI channel; the ME-5 must be in Play mode. Picking ports by hand works for patch changes even when SysEx replies don't come back - set the channel to the ME-5's.
