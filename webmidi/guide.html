ME-5 Editor · Web MIDI

User guide

An editor for the BOSS ME-5 guitar multi-effects that runs entirely in the browser. It shows a virtual pedalboard with the pedals in the same order as the signal path inside the ME-5. The browser talks to the pedal directly through a USB-MIDI interface, so there is no Python and no server to run.

What is this?

The ME-5 has MIDI ports, and every setting can be reached over MIDI. This editor uses that: the whole patch is on one screen, every control can be set with the mouse or a finger, and you hear the change at once. Patches can be saved, loaded back, and the factory sounds are always one click away.

This is the Web MIDI version. It does the same as the Python editor, but uses the browser's built-in MIDI access (the Web MIDI API). It therefore runs without installing anything on any computer or Android phone that has Chrome or Edge.

1What you need

  • Browser: Chrome or Edge on Windows, macOS, Linux or Android. Safari and iPhone/iPad will not work: they do not support Web MIDI.
  • A USB-MIDI interface. Use a good, opto-isolated one (e.g. Roland UM-ONE mkII or DOREMiDi). Cheap "USB2.0-MIDI" cables pass patch changes but not SysEx, so reading and writing patches fails.
  • On Android you also need a USB OTG adapter to plug the interface into the phone.

How does the computer connect to the pedal?

Computer / phoneUSB USB-MIDI interface2 × DIN ME-5 rear panel
interface OUT→ME-5 MIDI IN
interface IN←ME-5 MIDI OUT
  1. Switch the ME-5 off before plugging in the MIDI cable. Not required, but safer.
  2. Plug the interface's two DIN plugs in crosswise:
    • the interface plug marked OUT → the ME-5's MIDI IN socket;
    • the interface plug marked IN → the ME-5's MIDI OUT socket.
    Some cables are labelled the other way round, naming the socket the plug goes into. If patch changes don't work, swap the two plugs.
  3. Plug the interface into the computer or phone.
  4. Switch the ME-5 on and put it in Play mode. In Edit mode the pedal ignores SysEx, so the editor can neither read nor set sounds; only patch changes work. Any MIDI channel (1–16) is fine: Auto-detect finds it.

2Starting

The editor is a single web page, index.html in the webmidi folder. There are three ways to open it:

  • From a web address (HTTPS): if the page is hosted somewhere (e.g. GitHub Pages), just open its address. This is the easiest way, and the way it works on a phone.
  • Straight from the file: double-click index.html. If the browser doesn't ask for MIDI permission this way, use the next option.
  • From a local server: in the project folder run npx serve webmidi or python -m http.server -d webmidi, then open the http://localhost:… address it prints.

Important: don't run the Python editor's server at the same time. On Windows only one program can hold a MIDI port open, so the two editors would take the port from each other.

3Connecting to the ME-5

  1. Click Offline in the top right corner.
  2. The first time, the browser asks for permission to use MIDI devices (and SysEx). Click Allow. If you blocked it by mistake, click the icon at the left of the address bar and allow MIDI devices in the site settings.
  3. Then either:
    • Auto-detect: searches every port and MIDI channel for the ME-5 and connects by itself. This needs working SysEx.
    • By hand: pick the Output (to ME-5) and Input (from ME-5) ports, set ME-5 MIDI channel to the pedal's channel, and click Use these ports. Patch changes work this way even when SysEx doesn't.
  4. Once connected, the label turns green and shows the output port name and the MIDI channel.
  5. Go offline disconnects.

The editor remembers the ports you used last. When you reload the page it reconnects by itself if the interface is plugged in. If you unplug the interface while working, it switches to offline.

When offline, all edits stay in the editor; nothing reaches the ME-5.

Quick test: after connecting, change patch with ◀ ▶. If the number on the ME-5's display changes too, the connection works. Then press Read ME-5 to check SysEx: if it succeeds, all 64 patches are read from the pedal.

Patches (patch map)

All 64 patches are shown in a grid. The coloured dots in each cell show which effects are on in that patch, in the colour of the pedal. Click a cell to switch to that patch. Cells with a dashed amber border are bad patches. Click the Patches heading to fold the map away.

5Using the editor

Turning a pedal on and off: click its footswitch (the large numbered part). The CHECK LED lights when the pedal is on. The NS pedal is "off" at Threshold 0; switching it back on restores the last threshold used.

Knobs:

  • drag up or down with the mouse or a finger;
  • mouse wheel, one step per notch;
  • keyboard, when the knob has focus: ↑/→ and ↓/← one step, PgUp/PgDn bigger steps, Home minimum, End maximum.

GE-7 faders: drag them or use the mouse wheel.

Changing patch from the keyboard: ← and → go to the previous and next patch when no control or input field has focus.

What reaches the ME-5, and when?

  • Patch change: a Program Change is sent at once and the ME-5 switches.
  • Turning a knob, flipping a switch: about 0.1 s later the edited sound is sent to the ME-5's temporary memory, so you hear it right away. This is not saved yet. If you change patch, the edit is lost unless you press Write first.
  • Write: stores the sound in the current patch on the ME-5 for good.
  • Auto write: when on, you don't need to press Write. The sound is stored 5 seconds after your last change, or at once when you change patch.

6Saving to a file and loading

The Web MIDI version has no file folder of its own: files go wherever the browser saves downloads, and you load them from wherever you like. The format is the same .syx dump as in the Python editor and the original program, so files can be moved between them.

  • Save file…: type a name (the .syx extension is added for you) and click Save. The browser downloads the file, usually into the Downloads folder. The file holds the 64 patches in the editor. Unwritten edits (EDIT lit) are not included, so press Write first.
  • Load file…: a file picker opens; choose the .syx file. You can also drag the file onto the editor window. After loading, the editor holds the file's patches; they are not sent to the ME-5 until you Write them patch by patch.

7Repairing bad patches

If a patch slot in the ME-5's memory holds garbage (old pedals can get this from a flat backup battery), Read ME-5 still reads the rest. The editor puts the factory sound in place of each bad patch and marks it with a dashed amber border in the patch map.

The Repair N button then appears (N is the number of bad patches). After you confirm, it writes the factory sound into every bad slot on the ME-5.

If repaired patches go bad again after the pedal has been switched off, the ME-5's backup battery probably needs replacing.

8Troubleshooting

SymptomFix
"This browser has no Web MIDI"The browser doesn't support Web MIDI (e.g. Safari, iPhone). Use Chrome or Edge.
"MIDI access denied"MIDI permission was blocked. Click the icon at the left of the address bar, allow MIDI devices in the site settings, then reload. If you opened the file directly and no permission prompt appears, start it from a local server (section 2).
"No MIDI ports found"The interface isn't plugged in or wasn't recognised. Plug it in and open the connection dialog again.
"could not open any MIDI input"Another program (e.g. the Python editor's server or a DAW) holds the port. Close it and try again.
"ME-5 not found on any MIDI port"Check that the ME-5 is in Play mode and that MIDI IN/OUT are wired crosswise. If patch changes work with ports picked by hand but SysEx doesn't, the interface doesn't pass SysEx (see section 1).
Editor changes can't be heard and Read ME-5 fails, but patch changes workThe ME-5 is probably in Edit mode. Switch it to Play mode.
"Read ME-5" is greyed outConnect first (section 3).
An edit was lost after changing patchPress Write before changing patch, or turn on Auto write.

Manual mode: the original Raspberry Pi version switched the ME-5's manual mode with a relay. There is no MIDI command for it, so this feature is not available here.
